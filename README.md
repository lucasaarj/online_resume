# Portfólio — Lucas Gomes de Araujo

Site estático feito com HTML, CSS e JavaScript puro.

## Arquivos
- `index.html`: estrutura e conteúdo do site.
- `style.css`: layout, cores, responsividade e animações.
- `script.js`: menu mobile, animações de entrada, ano automático e botão voltar ao topo.

## Como visualizar localmente
1. Extraia o ZIP.
2. Abra a pasta no VS Code ou Zed.
3. Abra `index.html` no navegador. Para uma experiência melhor, use a extensão Live Server ou a extensão equivalente da sua IDE.

## Como publicar gratuitamente no GitHub Pages
1. Crie um repositório público no GitHub, por exemplo `lucas-portfolio`.
2. Envie os três arquivos (`index.html`, `style.css`, `script.js`) para a raiz do repositório.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`, depois salve.
6. Aguarde a publicação. O GitHub mostrará o endereço público do site na própria tela do Pages.

## Antes de publicar
- Confira telefone, e-mail, links e nomes dos projetos.
- Confirme se todos os repositórios estão públicos.
- Se quiser, substitua os elementos visuais ilustrativos dos projetos por capturas de tela reais.
